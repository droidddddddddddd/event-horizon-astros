# Mint implementation runbook (not deployed)
Use the official Metaplex Core Candy Machine CLI wizard on devnet first: https://www.metaplex.com/docs/smart-contracts/core-candy-machine/create . Do not use legacy Candy Machine V3.
Create Core collection with 250 bps royalties (verify marketplace support). Upload approved art and metadata to permanent storage. Create a machine for 1000 items with guard groups early/public/reserve, each with allocation guard 200/780/20 respectively; initialize each allocation counter using the official allocation guard route. Early requires allowlist proof and one mint per wallet; public two per wallet; reserve requires address gate to the disclosed reserve wallet. Use distinct mint-limit IDs. Set early end and public start to the same time; disable unguarded default minting. Verify payment destination and all guard settings on chain. Reserve is not guaranteed to be a specific rarity; disclose selection policy before mint. If using config lines, disclose pseudo-random selection is not cryptographically secure; for delayed reveal use committed hidden settings and independently review reveal assignment. Test wrong wallet, phase, price, allocation exhaustion and mint limits. Verify actual fees, collection authority and metadata. No mainnet until independent review. No keys in repo. Pump.fun token is launched separately by owner on same day as early mint; publish only verified address. Website links remain disabled until all checks pass.
