# Launch runbook
1. Deploy static site to Render (publish directory `.`) or GitHub Pages. Verify HTTPS and mobile.
2. Confirm project name, ticker, artwork ownership, official accounts and domain. Add URLs in launch-config.js.
3. Commission or generate original high-resolution layered art; approve 202 Common, 57 Uncommon, 81 Rare, 60 Epic, 20 Legendary (done) including five unique pieces. Existing 50 portraits and legendary archive are concept crops only.
4. Use the metadata validator with final assets. Upload immutable images and JSON to permanent storage; verify every URI.
5. Use maintained Solana NFT mint tooling (e.g. Metaplex Candy Machine) on devnet first. Independently review mint authority, collection verification, payment destination, price, supply, reveal and bot protection. Do not reuse exposed keys. No blockchain deployment code is included or audited here.
6. Decide whether to issue a token separately; confirm supply, distribution, vesting, liquidity and authority policy with legal/security review. Never imply guaranteed returns or NFT rewards. Publish actual verified mint addresses only after deployment.
7. Update privacy and sale terms with operator details, rights, jurisdiction and hosting practices. Test mint on devnet, then obtain independent review before mainnet.
8. Publish official links and set status live only when verified. Keep prelaunch site available meanwhile.

## Campaign
Day -7: reveal Original and the slogan. Day -6: release free reaction memes. Day -5: introduce five rarity tiers. Day -4: community fan PFP day. Day -3: reveal legendary archive. Day -2: publish transparent launch mechanics once confirmed. Day -1: security reminder and official links. Launch day: publish verified addresses, monitor issues, never invent scarcity. Post-launch: weekly mission log and fan art spotlight.
